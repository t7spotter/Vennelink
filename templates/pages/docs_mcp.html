MCP server

tools

Agents (Claude Desktop, Claude Code, Cursor, OpenCode, …) can manage your links over the Model Context Protocol. One endpoint speaks JSON-RPC 2.0 over HTTP — no stdio process, no extra dependencies. It reuses the REST API's keys, so an agent acts as exactly one user and can be cut off instantly by revoking its key.

Endpoint

{{ SITE_URL }}/mcp/

Stateless Streamable HTTP: send every JSON-RPC message as a POST; there is no session to open and no SSE stream. Requests without a valid key answer 401.

Authentication

Same keys as the REST API — exchange your password once (POST /api/v1/token/), then send the key as a header. Revoke it on the profile page and every MCP session goes dark with it. 

Authorization: Bearer <api key>

Connect a client

Add this server to your client's config (the shape below works for Claude Desktop/Claude Code, Cursor and OpenCode): 

{
  "mcpServers": {
    "retie": {
      "url": "{{ SITE_URL }}/mcp/",
      "headers": {
        "Authorization": "Bearer <api key>"
      }
    }
  }
}

Try it by hand

Any MCP client bootstraps with initialize, then calls tools. The same works from curl: 

curl -X POST {{ SITE_URL }}/mcp/ \
  -H "Authorization: Bearer $RETIE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "id": 1, "method": "tools/call",
       "params": {"name": "create_link",
                  "arguments": {"destination": "https://example.com/article"}}}'

# → {"jsonrpc": "2.0", "id": 1,
#    "result": {"content": [{"type": "text",
#      "text": "{\"code\": \"k3mQx9\", \"short_url\": \"…/k3mQx9\", …}"}]}}

Bad input is not a crash

Validation problems come back as an isError tool result with a readable message — only an unknown method or malformed JSON is a JSON-RPC protocol error. Link analytics go back at most 90 days per call.
